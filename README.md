# 🗡️ The World Manile (TWM)

Легковесная пошаговая RPG, написанная на чистом Python (`Tkinter` / `Pygame`). Игра специально оптимизирована для работы на ультрабюджетном и старом железе.

## 💾 Где скачать готовый .exe:
* **Dustore (RU):** https://dustore.ru/
* **Itch.io (Global):** https://arckadia.itch.io/the-world-manile

## 💻 Системные требования:
* **ОС:** Windows XP / 7 / 8 / 10 / 11
* **Процессор:** 1.0 GHz (Одноядерный)
* **ОЗУ:** 256 МБ
* **Место на диске:** ~70 МБ

## 🛠️ Запуск из исходного кода:
1. Установите Python 3.8+
2. Установите зависимости: `pip install pygame`
3. Запустите главный файл: `python 0.9.2.py`
